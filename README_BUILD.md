# Mis Recordatorios V2 — APK

Este proyecto incluye un workflow de GitHub Actions que compila automáticamente el APK.

1. Sube todos los archivos y carpetas del proyecto a tu repositorio.
2. Ve a la pestaña **Actions**.
3. Abre **Build APK**.
4. Espera a que termine correctamente.
5. En la ejecución terminada, baja a **Artifacts** y descarga **MisRecordatorios-V2-APK**.
6. Descomprime el ZIP del artifact y encontrarás `app-debug.apk`.
